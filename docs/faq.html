The wrist HUD / menu doesn't show up
  • Start SteamVR first, then the app (or turn on Settings → Start with SteamVR).
  • Only one copy can run. If it says it's already running, close the other one (check the tray / Task Manager for python).
  • Look at your wrist: with Look to show on, the HUD fades in only when you look at it. Turn it off in Mods → Wrist to always show it.
  • The menu lives in the SteamVR dashboard: press the menu button and look for the Fluff VR Stats tab at the bottom.
  • Wrong wrist? Settings → comfy + access → Left-handed mode, or Wrist → Placement to nudge it.
  • Still nothing? It may have started in safe mode (all mods off after 2 crashes). Settings → backup + help → Safe mode → mods back on.
Chatbox, avatar toggles or headpats don't work (OSC)
  • In VRChat: Action Menu → Options → OSC → Enabled.
  • Switch avatars once (or Options → OSC → Reset Config) so VRChat lists your avatar's toggles.
  • Headpats: Mods → Counters → Learn my headpat, then get a pat within 25 seconds.
  • Another OSC app on port 9001? Close it or change osc_listen_port in config.json.
Apps that fight with Fluff VR Stats
  • MagicChatbox: you both write the VRChat chatbox. Close it, or turn off Chatbox stats here.
  • XSOverlay / OVR Toolkit: both are fine together, but wrist menus can overlap. Move one of them (Wrist → Placement).
  • The Settings → Setup checklist tells you if any of these are running.
App key questions
  • Get it: join the Discord, type /key. Fluff Bot shows it (and DMs it to you).
  • Enter it: Settings → app key → enter, or the popup the first time.
  • Lost or leaked it? /resetkey makes a new one; the old one stops working.
  • One key works on up to 5 installs (PC, laptop, Quest, phone...).
  • Fluff Bot offline? The app keeps working, try your key later.
Global chat
  • No links, no personal info, slow mode is 1 message every 3 seconds.
  • Someone being mean? Tap mute next to their message (just for you), or report to send it to staff.
  • Staff bans work instantly everywhere, no update needed.
Low FPS
  • Open the Boost tab and tap boost all (everything is undoable).
  • Settings → Profile → Performance turns off everything that isn't a stat.
  • Wrist refresh 1x / sec saves a tiny bit more.
  • The Stats tab shows how much CPU + RAM Fluff VR Stats itself uses (it should be tiny).
Updates
  • Updates install by themselves when you start the app. Every update is signed: if the files don't match the signature, it doesn't install.
  • Turn auto updates off in Settings → general.
  • Your settings, key, kitty and badges are never touched. Old files are backed up in .update_backup/.
Send us your logs
  • Settings → backup + help → Copy logs. That copies the last part of logs/fluffvr.log.
  • Open a /ticket in the Discord and paste it with a screenshot.
