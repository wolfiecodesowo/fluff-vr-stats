🖐️ no wrist menu on Quest? use ur phone!

📵 Android phones only. the phone remote is not available on iPhone.

standalone Quest doesn't let apps draw menus on top of VRChat, so the hand/wrist menu from the PC version may not work on Quest. instead, ur phone becomes the menu 📱

  1. on the Quest: open the app, tap start chatbox, go to the Remote tab and look at the pair code
  2. on ur Android phone: open this page, download the same APK and install it (allow "install unknown apps")
  3. phone → Remote tab → find my Quest → tap it → type the pair code → connect

now u can flip avatar toggles, type in the chatbox, skip songs, run timers and turn mods on/off while u play. free, no account, just be on the same Wi-Fi.

playing PCVR with Air Link / Steam Link / Virtual Desktop? grab the PC version instead, it has the full wrist HUD.

🔄 updating

download the new APK and drag it into SideQuest, same as installing. no need to delete the old one, ur settings stay. the app's header shows which version u have, and it tells u when a newer one is out ✨

downloaded but still the old version? ur browser may have kept an old copy. the download is named with the version now (like FluffVRStats-Quest-0.5.0.apk), so make sure u drag in the newest one.

💻 how to install (easiest, with a PC)

  1. turn on Developer Mode for ur Quest in the Meta Horizon app on ur phone (Devices → ur Quest → Headset settings → Developer mode)
  2. install SideQuest on ur PC from sidequestvr.com and plug in ur Quest with a USB cable
  3. put on the headset and tap Allow on the USB debugging pop-up
  4. download the APK above on ur PC, then drag it onto the SideQuest window
  5. on the Quest: Library → filter → Unknown Sources → Fluff VR Stats :3

🥽 downloading on the Quest itself?

tapping download in the Quest browser saves the APK to ur Downloads, but the Quest can't install APKs by itself. u still need SideQuest on a PC (steps above), or an ADB app on an Android phone (like Bugjaeger) to install it.

▶ first time setup

  1. open Fluff VR Stats :3 and tap start chatbox
  2. open VRChat and turn on OSC: Action Menu → Options → OSC → Enabled
  3. (optional) Music tab → allow song info to show ur song

if the chatbox stops when VRChat opens, let us know in the Discord. that's the #1 thing we're testing in this beta!
